THE PROJECT

DOOM on a very different beast.

DOOM on the 3DO was never simply a PC port with the platform name changed. It was an ambitious conversion shaped by a completely different machine. A machine whose distinctive rendering architecture and hard technical limitations had an impact in why DOOM on the 3DO was so challenging.

PANDORA 2 is built with the mindset of 'what if the 3DO had shovelware?' Naturally.. the only way to find out was to build it! 23 levels, ripped apart, rebuilt, reshaped, around the 3DO's limits.

WHAT IS A PREZFILE?

The secret sauce behind the MEGAREZ!

The REZFILE is the main 3DO resource archive. It contains the game's normal resources.. textures, sprites, interface graphics, map resources and the other data that makes the 3DO version of DOOM what it is.

The PREZFILE is a companion resource archive used for replacements (a new feature in DOOM 3DO). PANDORA 2's PREZFILE tooling starts from the base REZFILE and creates a smaller archive containing only the resources that have been replaced or patched.

That means PANDORA 2 can override individual resources without having to rebuild and redistribute the entire base REZFILE. Replacement resources can include maps, wall textures, frontend graphics, sprites and other explicitly selected resources.

THINK OF IT THIS WAY

REZFILE
The original/base resource world.

PREZFILE
The PANDORA 2 override layer (like a PWAD).
